# AI Form Coach Landing Page

## Open in VS Code
1. Unzip the project.
2. Open the `ai-form-coach` folder in VS Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.

## Files
- `index.html` — page content/structure
- `styles.css` — responsive design + light/dark themes
- `script.js` — theme switch, mobile menu, demo form, animated score

The waitlist form is frontend-only for now. Connect it to your backend or form provider before production use.
